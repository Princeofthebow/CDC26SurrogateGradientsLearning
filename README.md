# Documentation for the code related to the paper *Costate control for nonlinear system identification with applications to neuroscience*

This repository provides the code, some examples and data files used to generate the results presented for the 2026 Conference on Decision and Control paper submission *Costate control for nonlinear system identification with applications to neuroscience* by T. B. Burghi, and Giovanni Pugliese Carratelli,
and Michael Everett Rule.

The script that should be run to obtain the results in the paper is found in surrogate_scripts/main_HH.jl.

To run the code, first install Julia (version 1.10.5 or more recent). Then in the root folder, follow the steps below:
i) run Julia
ii) in the REPL, enter the Package Management system by typing ']'
iii) create an environemnt by typing 'activate .' 
iv) then type 'instantiate'. 

This will install required packages and the code can be run.
